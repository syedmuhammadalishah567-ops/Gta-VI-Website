# GTA VI Hub

An unofficial, non-commercial fan site for Grand Theft Auto VI — built with plain HTML, CSS, and JavaScript.

## Features

- Live countdown to Rockstar Games' announced launch date
- The world of Leonida (Vice City, Port Gellhorn, Mount Kalaga, Leonida Keys, Grassrivers, Ambrosia)
- Character profiles for Jason, Lucia, and the supporting cast
- Standard vs. Ultimate edition comparison
- Artwork gallery with a lightbox and prev/next navigation
- Fully responsive, mobile-first layout

## Running locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
